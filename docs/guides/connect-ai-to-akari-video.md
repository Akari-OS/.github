# AKARI Video を AI（Codex / Claude）で操作する — はじめてガイド

AKARI Video は、**Codex や Claude のような AI から動画編集を直接操作**できます。
「今のタイムラインを見て」「ここをカットして」「字幕を付けて」と頼むと、AI が実際に編集を実行します。

このガイドは、初めての人が AI を AKARI Video につなぐまでを順番に説明します。

---

## 仕組み（ざっくり）

```
あなた → AI(Codex / Claude) ──(MCP) http://127.0.0.1:47616/mcp──▶ AKARI の窓口 ──▶ akari-video
```

- AKARI Video は **MCP サーバー**という小さな窓口を持っています。AI はそこに繋いで操作します。
- **AKARI で akari-video を開くと、この窓口が自動で立ち上がります**（ポート `47616`）。
  別途インストールや起動コマンドは不要です。
- 接続先は `http://127.0.0.1:47616/mcp`（あなたの PC の中だけ。外部には公開されません）。

> MCP（Model Context Protocol）= AI と外部アプリをつなぐ共通規格。Codex も Claude も対応しています。

---

## 準備（Codex / Claude 共通）

1. **AKARI Desktop を起動**する。
2. その中で **akari-video アプリを開く**。← これで窓口（`:47616`）が動き出します。
3. 編集したいプロジェクトを開いておく。

> これをやらずに AI から操作しようとすると「接続されていません / タイムアウト」になります。
> そのときは「AKARI で akari-video を開く」だけで直ります。

---

## Codex につなぐ

`~/.codex/config.toml` に次を追記します。

```toml
[mcp_servers.akari-video]
url = "http://127.0.0.1:47616/mcp"
```

保存して Codex を起動し直すと、`video_*`（タイムライン / 字幕 / エフェクト / 音声 / 書き出し など）の
ツールが使えるようになります。

---

## Claude（Claude Code）につなぐ

ターミナルで 1 コマンド実行するだけです。

```bash
claude mcp add --transport http akari-video http://127.0.0.1:47616/mcp
```

どのプロジェクトでも使いたい場合は、ユーザー全体に登録します。

```bash
claude mcp add -s user --transport http akari-video http://127.0.0.1:47616/mcp
```

登録できたか確認:

```bash
claude mcp list
```

## 使ってみる

AI に普通の言葉で頼むだけです。**最初に「状態を見て」と頼むのがコツ**（AI が現状を把握してから安全に編集します）。

例:
- 「今開いているプロジェクトの状態を見て」
- 「最初の無音部分をカットして」
- 「この動画に字幕を付けて」
- 「テロップの色を白にして上に寄せて」

AI が行った操作は AKARI Video の画面にも追従表示され、`元に戻す（undo）`で取り消せます。

---

## スキルで“賢く”使う（任意）

**スキル**とは、AI に「akari-video の使い方・作法」を教える説明書（Markdown 1 ファイル）です。
入れておくと、AI が毎回正しい手順（**まず状態を読む → 提案 → 適用**）で動いてくれます。

### スキルの置き場（Claude Code の場合）
- 自分のどのプロジェクトでも効かせる: `~/.claude/skills/<スキル名>/SKILL.md`
- そのプロジェクトだけ: `<プロジェクト>/.claude/skills/<スキル名>/SKILL.md`

### URL からスキルを入れて発動する流れ
1. スキルの **URL（SKILL.md へのリンク）を AI に渡す**。
2. 「このスキルを `~/.claude/skills/` に保存して、有効化して」と頼む。
3. AI がファイルを保存 → スキルが有効化されます。
4. あとは `/<スキル名>` と打つか、関連する依頼をすると**自動で発動**します。

## うまく動かないとき

| 症状 | 対処 |
|---|---|
| 「接続されていません」「タイムアウト」 | AKARI で **akari-video を開いているか**確認（窓口 `:47616` が動いているか）。 |
| ツールが見つからない / 古い | アプリを更新・再読み込みしてから、AI 側で MCP を**つなぎ直す**。 |
| どんな操作ができるか分からない | AI に「使えるツールを一覧して」と聞く（常に最新が返ります）。 |
